## 🔍 **Cách Xem Diagrams**

### **Option 1: Mở trực tiếp trong browser**
- Double-click vào file `.svg`
- Hoặc kéo thả vào Chrome/Firefox/Edge

### **Option 2: Mở trong VS Code**
- Cài đặt extension "SVG Viewer"
- Right-click file → "Open SVG Viewer"

### **Option 3: Chèn vào báo cáo**
- **Word**: Insert → Pictures → Chọn file SVG
- **PowerPoint**: Insert → Pictures → Chọn file SVG
- **PDF**: Export từ Word/PowerPoint

### **Option 4: Convert sang PNG/JPG**
- Online: svgtopng.com, convertio.co
- Tool: Inkscape, Adobe Illustrator
- Command: `convert diagram.svg diagram.png`
